## 과제(예측, 결과, 왜)
01. gl.clearColor(1.0, 0.5, 0.0, 1.0) 은 무슨 색일까요? 먼저 적어 두고 실행해서 맞는지 확인하세요.
- 예측: 주황 (RGBA => 빨강에 초록쪽이라 주황이었던 거 같음)
- 결과: 귤색 같은 주황
- 왜: 가산혼합 때문에 빨강100+초록50 => 주황

02. resize() 호출을 지우고 브라우저 창 크기를 바꾸면 어떻게 되나요? 왜 그럴까요?
- 예측: 화면이 찌그러져 보일 것. (resize => 말 그대로 화면 키우고 줄이면 리사이즈 하는 거라)
- 결과: 화면이 흐릿하거나 픽셀이 늘어나 보입니다.
- 왜: WebGL이 실제로 그리는 내부 해상도는 기본값인 300 × 150에 머물기 때문.
  
03. 'webgl2' 를 'webgl' 로 바꾸면 이 코드는 여전히 동작하나요? 콘솔에 무엇이 나오나요?
- 예측: 동작하지 않을 거 같음
- 결과: 정상동작 / 콘솔 뭐 안 나옴
- 왜: 현재는 webgl에서도 지원하는 것만 하고 있기 때문임.
